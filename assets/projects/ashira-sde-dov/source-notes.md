# Ashira Sde Dov Showroom Prototype Sources

Date: 2026-06-26

This folder is a clean v2 prototype package for the Ashira showroom factory.

## Assets

- `ashira-hero-concept.jpg` is an original generated concept image for the project hero. It is not an official developer render.
- `ashira-facade-concept.jpg` is an original generated concept facade for the apartment picker. It is not an official sale elevation.
- `model-prototype.glb` is a temporary massing model copied from the existing prototype rail so the v2 page can test model-viewer behavior. Replace it with an official BIM/GLB or approved generated model before a commercial launch.

## Public Use

Keep the illustrative wording visible until all commercial data is verified:

- official project model or approved visual;
- approved sale plans;
- approved unit inventory;
- approved pricing or price policy;
- developer-approved media gallery, video and interior tour.

## Clean V2 Rule

The Ashira v2 implementation uses only `.nlv2-*` classes and `data-nlv2-*` attributes. Do not mix it with `.nlps` or `.nlp3d` selectors.
