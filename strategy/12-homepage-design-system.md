# Homepage Design System

Homepage role:
The homepage must communicate that NadLan is a serious real-estate portal, not a collection of experiments.

First viewport goals:
- Clear portal identity.
- Search/discovery path.
- New projects.
- Professionals.
- Tools/guides.
- Trust indicators.

Design principles:
- Hebrew RTL first.
- Dense but readable portal UX.
- Premium without pretending data is official when it is not.
- Avoid decorative-only UI.
- Use real site signals: project counts, professional counts, tools, and verified sources only when current. `NEEDS_VERIFICATION`

Do not redesign until:
- Stage 1 public trust is green.
- Site architecture decisions are stable.
- Main P0 pages are mapped.
