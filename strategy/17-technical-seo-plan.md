# Technical SEO Plan

P0 checks:
- Indexability and noindex policy.
- Canonicals.
- Sitemaps.
- Robots.
- Titles/meta/H1.
- Breadcrumbs.
- Structured data.
- Core public-page console errors.
- Mobile overflow.
- Performance on key templates.
- Internal links from hubs to money pages.

Blocked/current:
- Stage 1 final public trust proof waits for UPress theme pull/cache clear.

Do not:
- Start mass page generation before canonical/noindex rules are proven.
- Use template pages with placeholder text.
- Treat browser screenshots as optional for visual changes.
