# NadLan Money Keyword Expansion Mandate

Status: active operating rule, 2026-06-21.

## Non-negotiable position

NadLan is not avoiding any Israeli real-estate category because a competitor is strong.

Every keyword class that either makes money directly or supports a money page belongs in the long-range roadmap. Priority is allowed. Surrender language is not.

Acceptable reasons to stage a keyword later:

- the page needs real listing supply;
- the page needs official data;
- the page needs legal/tax/financial review;
- the page needs verified professional or developer records;
- the page needs licensed/official visual assets;
- the page would cannibalize a stronger canonical page unless mapped correctly.

Unacceptable reasons:

- "Yad2 owns this";
- "Madlan owns this";
- "too competitive";
- "not our niche";
- "too broad";
- "only long-tail";
- "hard to rank".

## Required coverage classes

The keyword universe must eventually cover all of these classes:

1. Resale listings: national, city, neighborhood, street/area, property type, room count, price band, feature filters.
2. Rentals: national, city, neighborhood, room count, price band, owner/broker, furnished, partners, short/long term.
3. New projects: project, developer, city, neighborhood, tower, delivery date, floor, view, apartment type, asset/showroom.
4. City and neighborhood intelligence: prices, rent, yield, schools, transport, planning, safety, urban renewal, market movement.
5. Valuation and data: property value, price per square meter, recent transactions, price index, confidence ranges.
6. Mortgage and financing: calculators, affordability, rates, tracks, early repayment, foreign buyers.
7. Tax and transaction costs: purchase tax, betterment levy, capital gains, lawyer, broker, renovation, holding costs.
8. Professionals: realtors, lawyers, mortgage advisors, appraisers, inspectors, architects, designers, contractors, project managers.
9. Urban renewal: Tama 38, Pinui Binui, tenant rights, refusing tenant, permits, planning, city-level renewal hubs.
10. Investors: rental yield, cash flow, risk, location comparison, foreign investors, luxury, long-term holds.
11. International investors: English buyer/investor funnel, Aliyah, remote buying, lawyers, taxes, mortgages, city hubs.
12. Luxury and special assets: penthouses, towers, seafront, private sales, premium projects.
13. Commercial and land: offices, shops, lots, zoning, building rights, ILA, employment zones.
14. Trust and comparison: Yad2 vs Madlan vs NadLan, fake listings, developer checks, professional verification, due diligence.
15. AEO / AI search: FAQ, HowTo, glossary and concise answer blocks that support canonical money pages.

## Anti-cannibalization rule

Before creating or commissioning any content:

1. Find or create the row in `strategy/04-keyword-master-universe.csv`.
2. Assign one canonical URL owner.
3. Define whether the page is a money page, support page, directory page, tool page, project page, or data page.
4. Define the parent page and required internal links.
5. Confirm it does not compete with an existing stronger page.
6. Set readiness status: backlog, drafting, review, legal, ready, published, holding.

No writer, designer, developer, or AI tool should produce public content outside this system.
