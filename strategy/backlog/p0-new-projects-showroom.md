# P0 New Projects Showroom

Objective: make Rainbow and Dimri credible showroom prototypes that can be replicated.

## Tasks

1. Define source asset state per project: official, concept, missing.
2. Replace ugly or misleading concept art with a clean design direction or missing state.
3. Keep 3D context model separate from facade/unit picking unless real unit mesh exists.
4. Make facade picker real image/render + polygons, not generated rectangles.
5. Make selected apartment card dismissible and non-overlapping.
6. Wire view/tour/floor-plan states with honest missing/error UI.
7. Attach unit context to lead/WhatsApp/form.
8. Produce contractor manual for replacing concept assets with official assets.

## Acceptance

- Buyer can select a unit without confusion.
- Mobile does not overflow.
- No old selector layer stacks over new selector.
- Missing assets are visible.
- Lead payload includes unit context.
- Screenshots and click journey proof committed.

## Official Asset Package To Request From Contractor

- facade/elevation render.
- site plan.
- floor plans.
- GLB/BIM if available.
- interior renders or tour URL.
- unit inventory/status.
- approved price ranges and disclaimers.
