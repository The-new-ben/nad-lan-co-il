# P2 Programmatic SEO

Objective: scale pages only after templates, data, and QA gates are proven.

## Candidate Page Types

- price guide by city/neighborhood.
- project comparison.
- investor yield.
- school/transport/environment.
- glossary/legal terms.
- professional category by city.

## Preconditions

- source data exists.
- canonical registry prevents cannibalization.
- template passes QA.
- no fake inventory/data.
- content has unique local value.

## Acceptance

- each generated page has source data and unique paragraphs.
- no indexation of empty/thin pages.
- internal links are generated correctly.
- sample batch reviewed manually before scale.
