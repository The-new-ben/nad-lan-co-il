# Cannibalization Map

Purpose:
Prevent NadLan from creating many weak pages that compete with each other for the same buyer intent.

Rules:
- One primary URL per keyword intent.
- Supporting spokes must link up to the primary hub.
- City/project/professional pages must have unique data or remain noindex.
- Glossary definitions should not target existing money-page keywords.
- Calculators should not duplicate guide pages; they should complement and link.

Immediate tasks:
- Export current URL, title, focus keyword, index status, canonical, and page type. `NEEDS_VERIFICATION`
- Map every P0 keyword to one target URL.
- Mark duplicates as consolidate, redirect, canonicalize, or noindex. `NEEDS_VERIFICATION`

Do not:
- Create programmatic city pages without unique inventory/data.
- Create multiple "new projects" hubs with overlapping Hebrew/Latin slugs.
- Publish placeholder sitemap or directory pages.
