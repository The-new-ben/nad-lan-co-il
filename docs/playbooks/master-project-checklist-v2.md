## שכבה 0 — חוקי הבעלים (עוקפים כל שורה אחרת; הפרה = כישלון סשן)

- **הרשימה השחורה** (אסור בשום מצב UI): "בהמתנה לחומרי היזם", "יחליף אותו עם קבלתו",
  "בבדיקה מול היזם", "יוצגו עם קבלת נתונים", "תוכנית תתווסף", "טרם התקבלו", "מחכים
  ליזם", "אין שרטוטים", "0 חדרים", "כיוון בבדיקה", "· בקרוב".
- **unknown = מושמט**, לעולם לא מוכרז. המחשה ממלאת חלל חזותי ומסומנת "הדמיה להמחשה"
  (בכיתוב, לא על התמונה) — היא לעולם לא הופכת למחיר/מלאי/כיוון/סטטוס מוצהרים.
- **חוק אדיטיבי:** יכולת קיימת לא נמחקת ולא מוחלפת ב-CSS-דמו. כל פער מסווג
  RETAINED/REUSED/WRAPPED/EXTENDED/SIMULATED/REPLACED/REMOVED — ‏REMOVED דורש מילת בעלים.
- **קפואים:** ריינבו, DUO (עד מילתו), קרן הטרקוטה, פנימיות engine.js, סניפטי x-einstein,
  המאמר העברי המוגן.
- **אין 301 לעולם. אין pagination.** (חבילת-העל שקדמה ל-Aurelia המליצה 301 לעמודים
  עם יורש — לא אומץ.)
- **חוק ה-URL (ברזל 9):** אין מילה פעמיים ב-URL; סלאג חדש לא לוקח מילת-ראש תפוסה;
  לפני כל סלאג — `tools/gsc/url_word_audit.py`. סלאג פרויקט = מותג-תחילה.
- **מאמרי ענק (5,000 מילים ×5 שפות) נכתבים ב-ChatGPT של הבעלים** מבריף — לא ע"י agent.
- **עדות:** כל "ירוק" נושא מחלקת ראיה — eyes (צילום שנצפה) / code (DOM/שרת) — לעולם לא
  "אמור לעבוד". הנורות לא חוסמות שמירה/פרסום (זו מערכת דיווח, הבעלים מחליט).
- **אחרי כל דיפלוי:** ספוט-צ'ק ריינבו + H-Infinity + בית.

## שכבה 3 — בחירת דירה (החוזה המדעי; מחליף stage_x/y לתמיד)

- שרשרת זהות אחת: `GLB anchor/mesh → hit → unit_id → כרטיס → תוכנית → מפה/קרן → נוף
  → פנים → סטודיו → ליד`. ‏`unit_id` הוא המפתח היחיד; אין עותק מקומי.
- שלוש שכבות: Tier A ‏`UNIT_PICK__{id}` (BIM, היעד); Tier B ‏surface-hit
  (anchor+floor-band+normal+distance — המסלול החי); Tier C ‏hotspot מוקרן
  (`queryHotspot`, ‏44px, occlusion probe, לעולם לא top/left ידני).
- tap≤6px/900ms בוחר; drag מסובב; ‏touch-action: pan-y; ‏Enter/Space; ‏צפיפות: עד 8
  נקודות דסקטופ / 5 מובייל + הנבחרת תמיד.
- `stage_x/y` = ‏legacy בלבד (`runtimeAllowed=false`).
- הרשימה המחייבת: 67 הבדיקות ב-`data/unit-selection-audit.json`.
