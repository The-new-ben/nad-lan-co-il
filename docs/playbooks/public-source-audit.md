# נוהל קבע: ביקורת View-Source ציבורי (פקודת בעלים 30.8.2026)

**החוק:** כל סשן, ועל כל שינוי — סורקים את ה-HTML הגולמי הציבורי (מה שקליק-ימני ו-Googlebot
רואים, בלי JavaScript), שומרים snapshot בלתי-משתנה, ומשווים לקודם. שיטתי ועמוק. ה-DOM
המרונדר אינו תחליף: title, canonical, hreflang, favicon, schema וסדר הטקסט נקבעים ב-raw.

## הכלי

```bash
python tools/source_audit.py
```

- בלי ארגומנטים — סורק את רשימת המעקב (בית, קטלוג, צי התלת-ממד, אקו סיטי, tours).
- עם URL-ים — סורק אותם; `--list` מציג את המצאי.
- כל עמוד: נורה (ירוק/צהוב/כתום/אדום) + הבדיקות + **DIFF מלא מול ה-snapshot הקודם**
  (שדות ראש, ספירות, סקריפטים שנוספו/הוסרו, דלתא בייטים).
- ‏Snapshots: ‏docs/source-snapshots/<slug>/<UTC>-<sha12>.html — לעולם לא נמחקים ולא
  נדרסים (שרשרת הראיות). רישום: ‏registry.json (עד 40 רשומות לעמוד).

## מה נבדק בכל עמוד

status/bytes/זמן · title+אורך · meta description+אורך · canonical (חייב ×1) · robots ·
hreflang · favicon · **h1 (חייב ×1)** · בלוקי JSON-LD + כפילויות FAQPage/BreadcrumbList ·
ספירת scripts/styles + דיפ-סט של src-ים · id כפולים · og:image · מקפים ארוכים בטקסט הגלוי ·
**הרשימה השחורה המלאה** · מילים פנימיות (Codex/Lovable...) · מיקום פס "אתר עצמאי" (חייב
בפתח המאמר, לא למעלה) · דליפות ecocity-render · נוכחות payload.

## מתי מריצים (חובה)

1. **פתיחת סשן** — ריצת watchlist מלאה; ‏DIFF לא-מוסבר = ממצא לדווח לבעלים.
2. **לפני כל שחרור** — על העמודים שהשינוי נוגע בהם (baseline לפני).
3. **אחרי כל שחרור** — אותם עמודים + בקרות (ריינבו + בית); ה-DIFF חייב להכיל רק את
   מה שהשחרור התכוון לשנות. הפתעה ב-DIFF = עוצרים ומדווחים.
4. עמוד חדש — מצטרף ל-WATCHLIST בכלי באותו קומיט.

אין לעדכן baseline "כדי להחזיר ירוק": קודם קוראים את ה-DIFF, מסווגים מכוון/לא-מכוון,
ורק אז השינוי נחתם (העיקרון מהמתכון של אורליה, checklist v2 R17).
