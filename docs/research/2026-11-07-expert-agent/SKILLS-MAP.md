# The NadLan advisor: skills map (HAD-680, 7.11.2026)

What a 40-year Israeli real-estate veteran does across a deal, turned into the advisor's skills: for each one, what the advisor does, the site tool or data it uses, and the line it never crosses. The line comes from three places: Israel's Real Estate Brokers Law (the site stays a publisher, s.2(c)), the professions reserved by law (lawyer, appraiser), and the honesty law of the site (no invented prices, inventory or dates).

Sources: `israel-deal-practice.md` (Israeli practice and law, sources retrieved 7.11.2026) and `world-ai-assistants.md` (Zillow, Redfin, Compass, Rightmove, Zoopla, REA, Madlan AI and others).

Legend for "how": **T** = a server tool computes it from the site's own data file (the number is never the model's); **P** = from the page the visitor is on, attributed "לפי העמוד"; **K** = from the advisor's dated knowledge block (law and official guides); **L** = a link to the site's own page or calculator.

## What the world's best do that we copy (and what we do not)
- Copied: inside the page, not a bubble (Redfin, Rightmove, Homes.com); questions about the page on screen first (59% of Ask Redfin questions); affordability from the visitor's own numbers; honest "I don't know"; the next step in the same conversation; escalate to a human on offers, value and contracts (NAR kit); AI disclosure at first contact and a persistent label (EU AI Act Art. 50 style); no description of an area by who lives there.
- Not copied: a fair offer price (Zillow does it only because Zillow is a licensed brokerage); booking tours (Redfin is a brokerage); memory across visits (needs login and a privacy decision).
- Not built yet (proposals): a second check on the answer for steering words before it is shown (Zillow runs a classifier on question and answer); a comparison of two projects side by side; a QA log of anonymised conversations (needs Ben's privacy decision).
