### 8.4 THE MOAT: "איזה כלי של דקל מתאים לי" + "כתב כמויות בפורמט דקל, נסו בעצמכם"
Two [nadlan_tool] mounts.
- **Chooser:** pick a role (רוכש דירה בשינויי דיירים / קבלן שיפוצים / מפקח או מנהל פרויקט / רשות או חברה שמוציאה מכרז / שמאי או יזם / מנהל נכס). Output: the 1 to 3 rows of Table B that fit, the official address, and the Dekel price list from Q3 that the tool uses (link).
- **BOQ line builder:** rows with קוד סעיף (free text, e.g. פרק.תת פרק.סעיף), תיאור, יחידה, כמות, מחיר יחידה (entered by the reader). Output: total per chapter, project total, optional contingency %, VAT line at 18% as an editable parameter, print and CSV. No stored prices. This replaces the invented numeric example with the reader's real numbers.
- Why a moat: the ranking set has zero tools and no page maps Dekel's tools to project stages with their addresses; it serves both the informational and the navigational searcher without pretending to be the login page.

### 8.5 Infographics
1. **"מסלול כתב כמויות בדקל"**: five steps as a horizontal strip (פירוט, אומדן, קבלנומט, השוואה, מעקב), each with the file type in and out (Excel, PDF, קבצי מכרז). Design brief (owner law 13.10): the look of an exported tender file: white sheet, graphite grid, ink-blue step numbers and file-type tags set like spreadsheet column heads; faces IBM Plex Sans Hebrew and IBM Plex Mono (codes, file names). Why not the default: it shows the reader the files they will really handle, with no cream, gold or neon-on-black.
2. **"שלוש החברות של קבוצת דקל"**: who does what (מחירונים / תוכנה / מכרזים), answering the literal query "דקל תוכנה".
