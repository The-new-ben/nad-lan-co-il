# Is it one intent? Google result overlap for the new-projects family (9.11.2026)

Method (the practitioners' test, not Google's word): two phrases share an intent when Google's page-1 results for them share URLs.
The common bar among SEO practitioners is about 3-4 shared URLs in the top 10. The input is the hand-read result pages in `serp.md`
(Ben's Chrome, google.co.il, 9.11.2026). Counted: exact same URL (domain + path) on page 1 of both phrases.

| Phrase pair | Shared URLs | Verdict |
|---|---|---|
| פרויקטים חדשים ↔ דירות מקבלן | 4 (madlan Israel, dimri, yad2 TLV, nadlan.com) | same intent |
| דירות מקבלן ↔ דירות חדשות מקבלן | 6 | same intent |
| דירות מקבלן ↔ דירות חדשות למכירה | 5 | same intent |
| פרויקטים חדשים ↔ דירות חדשות | 4 | same intent (plus a news layer in the AI box) |
| פרויקטים חדשים ↔ פרויקטים חדשים בישראל | 3 | same intent |

## What this says, honestly
1. **The core is ONE intent:** פרויקטים חדשים, דירות מקבלן, דירות חדשות (מקבלן / למכירה), פרויקטים חדשים בישראל. Ben is right: one page.
2. **Immediate occupancy, deals and off-plan are sub-intents of the same family**, not separate topics. They share 3-4 URLs with the core.
3. **The warning.** On those three sub-intents the #1 result today is a dedicated filtered view:
   - Yad2's "14 פרויקטים... לאכלוס קרוב" URL, with the count in its title;
   - Yad2's "פרויקטים חדשים במבצע" hub;
   - developers' "ready flats" pages.
   One page can win them only if each sub-intent has a strong, high, self-contained section: its own heading in both forms (באכלוס / לאכלוס), a live count, a filter, a table and a map layer. A buried section will not do it.
4. **Informational phrases are a different intent and stay on the guides:** "קניית דירה מקבלן", "מה זה דירה על הנייר", "איך עובד מבצע 20/80". Google shows articles for these, not lists.
