Method as in serp-he.md: autocomplete = real Google Suggest (`hl=ru`, `gl=il` for Russian speakers in Israel and
`gl=ru` for abroad); result lists = the WebSearch index; PAA not observable (PAA-proxy below).

## 1. Headline finding
**Nobody searches this project in Russian, and no Russian page about it exists.** Russian autocomplete for
"H Infinity", "Хагаг", "Инфинити Тель Авив", "Сумейль", "Сомайль", "башня Инфинити Тель-Авив" returns nothing
relevant (control-theory terms, "fufu", Warframe). Russian speakers who know the project type its Latin name
("h infinity tower tel aviv", "hagag group") or Hebrew. The Russian page therefore wins on the **generic intents**
(buying in Tel Aviv, new towers, tax, mortgage, repatriates) and uses the project as the concrete, fully-sourced case.
Zero competition for the entity in Russian = the first complete Russian page owns it.

  Latin. Recommendation: "комплекс Somail (Сумейль)" on first mention, then "Somail".
