## Open genericity item

The repository has shared v3 files and one governed Einstein package, but the current surface is
still Einstein-shaped. The playground pins Einstein's experience decision and current tool, scene
and anchor profile; CSS pins the `open-frame` scene hook; PHP pins current zero-inventory, North,
tool/capability, group/routing and Hebrew-copy policies. These are documented implementation gaps,
not permission to fork the runtime or claim that an archetype provider already exists.

Acceptance requires registry/package-supplied decisions and profile values, one unchanged runtime
passing Einstein and a second package with different valid IDs/cardinalities/language/archetype
requirements, fail-closed cross-project mismatch rejection, and no project-specific identifier,
scene/style hook, copy or fixed policy in shared runtime files.
