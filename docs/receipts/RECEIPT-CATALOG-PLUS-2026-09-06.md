## מלכודות 7.9 (לזכור)
- **`position:relative` על פין של Mapbox** מזיז אותו מאות פיקסלים: Mapbox ממקם markers עם position:absolute + transform. לעולם לא לקבוע position/transform על אלמנט המרקר.
- **clusterMaxZoom חייב להיות שלם** (10.6 → "Invalid array length" מ־supercluster).
- **בריחת אסקייפ כפולה**: Code Snippets מוריד רמת סלאשים אחת, heredoc של PHP עוד אחת. כדי לקבל `
` ב־JS כותבים ארבעה בקסלשים בקובץ. (deploy עם `'
'` אחד = SyntaxError שהשבית את המפה לכמה דקות.)
- **`.mapboxgl-marker{width:auto!important}`** גובר על width של נקודה; צריך סלקטור חזק יותר עם !important.
- הקונסול של חלונית הדפדפן צובר הודעות מכל הניווטים; לבדוק פורמט הודעה חדש, לא נוכחות של ישן.
- Headless Chrome עם UA של מובייל ב־390px לא מכבד viewport meta: צילומי מובייל אמינים רק מאמולציה (pane mobile preset).
