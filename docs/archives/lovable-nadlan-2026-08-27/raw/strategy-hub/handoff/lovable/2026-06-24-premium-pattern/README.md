## Honest statement

The current live WordPress behavior is version 1.69.32. It proves authored apartment units plus row-aligned surface tap behavior. It does not prove exact per-window picking inside the building model.

That is not premium enough as the final investor-facing product. It is a usable bridge if the visual shell, selected-apartment panel, mobile layout, and public copy are replaced by the premium pattern in this packet.

## What Codex should implement first
