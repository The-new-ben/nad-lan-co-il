### Critical implications of head-term data

1. **"מדלן" 74,000/mo, KD 33** is the single biggest real-estate query in Israel. People type the brand to enter the site. NadLan must build /vs/madlan AND publish a brand that becomes a search term (long game), AND outrank madlan on `area-info/<hood>` pages where the brand-prefix doesn't lock the query.
2. **"מחיר למשתכן" 74,000/mo, KD 43** — equally massive. SERP is fully government-dominated; NadLan must build a **live tender + lottery tracker** that ingests dira.moch.gov.il + arcgis lottery maps. That's the only realistic wedge.
3. **"דירות להשכרה" KD 22** is genuinely EASIER than "דירות למכירה" KD 50 — flip the build order if needed. R2's "sale first" assumption is wrong.
4. **City head terms are all KD 0–19** — programmatic city pages win the long-tail mass even without brand authority.

## 12. Reports G3–G11 — frameworks anchored to data above

Below are concise frameworks for each downstream report. None are written in full here because the user explicitly demanded no fabrication: each one needs at least one more data-gathering pass before being shipped as a finished document. The frameworks are the contract for what each report MUST contain, not the report itself.

### G3 — Internal Linking Graph (framework)

- Hub → Spoke: `/rent` links down to all 13 city rent pages; each city rent page links back up to `/rent` and laterally to `/sale/<city>`.
- Spoke → Tool: every city sale/rent page links to `/tools/mortgage-calculator`, `/tools/purchase-tax-calculator`, `/tools/tabu-check`, plus `/pro/real-estate-lawyers/<city>`, `/pro/home-inspectors/<city>`, `/pro/mortgage-advisors/<city>`.
- Tool → Spoke: each calc links to relevant city pages by query intent.
- Hood → City: every `/sale/<city>/<hood>` links UP only (no hood→hood until clusters mature).
- Glossary → Tool: every glossary entry links to its companion tool (e.g. /glossary/capital-gains-single-home → /tools/capital-gains-calculator).
- Anchor-text policy: exact-match for first link, partial for subsequent, no more than 3 exact-match anchors per source page.
- Breadcrumb: BreadcrumbList schema on every non-home page, max 4 levels.
- Equity routing: 80% of footer/global-nav slots → P0 list. Sidebar/related-content → P1.

### G4 — Programmatic Page Spec (framework)

For each template T1–T25 (city sale, city rent, hood, facet, project, developer, urban renewal city, pro-city, commercial sub-city, etc.) define:
- Required minimum data fields (e.g. T1 city: ≥50 listings, ≥3 hoods, ≥1 sentence of city editorial, ≥1 schools/transit/POI stat).
- Anti-doorway gate (page returns 404 or `noindex` until thresholds met).
- Sitemap shard (one shard per template, max 5,000 URLs/shard, daily rebuild for listings, weekly for hoods).
- Freshness/decay: listings page must update within 6h; if no new listings in 60 days, demote to `noindex,follow`.

### G5 — i18n & Hreflang (framework)

URL strategy:
- HE primary: `/<path>` no prefix.
- Mirrors: `/en/<path>`, `/fr/<path>`, `/ru/<path>`, `/ar/<path>` (AR pending manual SERP audit).
- `<link rel="alternate" hreflang="he" href=…>` and `x-default` on every page.
- Bidirectional return-tags enforced by build-time generator; broken pair = build fails.
- Translation QA: bilingual editor sign-off per page before index.
- Cultural QA: FR variant must reference Aliyah-specific concerns; RU variant must reference Aliyah + investment; EN variant must reference foreign-resident tax brackets.
- RTL: HE/AR full RTL; LTR mirror under EN/FR/RU. No directional CSS hacks beyond `dir` attribute.

### G6 — Data Pages Spec (framework)

Sources, with cadence and verification:
- **CBS (Israel Bureau of Statistics)** — home-price index, monthly. ETL via gov.il open-data CSV. Cite source on every chart. Methodology page mandatory.
- **BOI (Bank of Israel)** — prime rate, mortgage stats. Daily prime rate, monthly mortgage origination.
- **RMI (Israel Land Authority)** — tenders, weekly. ETL via gov.il tender JSON. Live tracker page.
- **MUNI** — local plans, building permits, irregular. Per-city scraper.
- **Courts.gov.il** — receivership listings, irregular PDF. LEGAL_REVIEW required before publishing.
- **MOH (Ministry of Housing) + dira.moch.gov.il** — Mehir Lamishtaken lotteries, irregular. Live lottery page.
- All data pages emit `schema.org/Dataset` + `Dataset.creator`, `Dataset.distribution`, `Dataset.temporalCoverage`.
- Anti-misinformation guardrail: every numeric statement has a footnote with source URL + date pulled.

### G7 — Pro Directory Verification (framework)

Per vertical, registry source + verify endpoint:
- Lawyers (`עו"ד מקרקעין`): Israel Bar Association public registry. Verify by license # + name match. LEGAL_REVIEW: do not display "specialty" without an authoritative source.
- Appraisers: Council of Real Estate Appraisers registry.
- Home inspectors: trade association list (Israel currently has no statutory registry — disclose this on the directory page).
- Mortgage advisors: Capital Markets Authority list of licensed advisors.
- Contractors: `רשם הקבלנים` open-data (gov.il). License # + class + status.
- Agents (`מתווך`): Brokers Registry per `חוק המתווכים`. License # mandatory; unverified profiles never appear in primary nav.
- Claim flow: pro claims listing → email verify → license # match → manual review for first 6 months → auto after.
- Badge logic: Verified (license matched), Premium (paid), Top-rated (review threshold). Never a "Pro" badge with no license check.
