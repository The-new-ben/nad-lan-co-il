# NadLan Rescue Showroom Theme

This is a standalone rescue theme package. It is designed to render one clean showroom layer only.

## Install
1. WordPress Admin → Appearance → Themes → Add New → Upload Theme.
2. Upload `nadlan-rescue-showroom-theme.zip`.
3. Activate.
4. Open:
   - `/`
   - `/projects/`
   - `/projects/ashira-sde-dov/`
   - `/projects/ashira-sde-dov-en/`

## What it includes
- Clean homepage / project catalog.
- Project pages for Ashira, Rainbow and Dimri Yama.
- Language URLs: HE, EN, FR, RU, AR.
- One renderer: `#nl-root`.
- A safety filter that removes a legacy `<main class="nlv2-showroom">` block from rendered post content.
- Optional REST lead endpoint: `/wp-json/nadlan-rescue/v1/lead`.
- Private lead storage under `nadlan_rescue_lead`.

## What it does not do
- It does not edit existing post content.
- It does not deploy to your live site by itself.
- It does not install multilingual plugins.
- It does not promise official developer inventory or pricing.

## Reversal
Switch back to the previous theme. No existing content is deleted.
