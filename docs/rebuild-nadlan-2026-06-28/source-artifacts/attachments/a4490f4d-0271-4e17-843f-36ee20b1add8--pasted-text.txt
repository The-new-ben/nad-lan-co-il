Recommendation: Google's <model-viewer> web component + a glTF/GLB per project. It's a drop-in tag (no build pipeline — fits your WP inline echo), gives free 360° orbit out of the box (kills "can't rotate 30/60°"), renders real 3D geometry (kills "doesn't look like a building"), has a native hotspot API for clickable apartments, lazy-loads via a poster image (CWV-safe), and gives AR on mobile for free. Same pattern clones to every future project.

The don't-wreck rule (critical): render <model-viewer> only when a project_model_glb meta exists; otherwise fall through to today's working CSS tower. Existing projects stay exactly as they are; only upgraded ones get the real model. Both reuse the same unit list, side console, and stage-card.

How each project GETS its 3D model — the replication pipeline (the scalable keystone)
Fast/cheap, real footprint+location: Blender + Blosm add-on → "Get OSM" at the project lat/lng → extrudes the real building footprint to floors × 3m → export .glb. Matches real shape and position.
Premium hero projects: import developer BIM/render → decimate → bake facade → GLB.
Optimize (mandatory): npm i -g @gltf-transform/cli then gltf-transform optimize in.glb out.glb --texture-compress webp --compress draco. Draco cuts mesh 60–90% (20MB→3–5MB), decoder is a one-time ~120KB. Budget: GLB ≤ 4MB, poster ≤ 80KB WebP.
