JS — tap toggles tooltip, click selects (do NOT add a second selector — call existing selectUnit):

document.addEventListener('click', function(e){
  var h = e.target.closest('.nlp3d-hotspot-hit'); if (!h) return;
  if (h.getAttribute('aria-disabled') === 'true') { e.preventDefault(); return; }
  // First tap (no other tip open): just show tip. Second tap (already open): select.
  var alreadyOpen = h.classList.contains('is-open');
  document.querySelectorAll('.nlp3d-hotspot-hit.is-open').forEach(function(n){ n.classList.remove('is-open'); });
  if (!alreadyOpen) { h.classList.add('is-open'); }
  else { selectUnit(h.dataset.unit, 'hotspot'); }            // existing fn
});
document.addEventListener('keydown', function(e){
  if (e.key === 'Escape') document.querySelectorAll('.is-open').forEach(n=>n.classList.remove('is-open'));
});
This is the "tap-to-preview, second-tap-to-commit" pattern — solves "no hover on mobile" cleanly, and reduces accidental selects.

On the "factory" / one-shot a new project (honest)
You CAN one-shot a prototype-grade project today: research, Hebrew SEO copy, generated massing GLB (OSM/Blosm), unit JSON with status/recommended/price-estimate, schema, Chrome QA, manual. All marked "הדמיה / אומדן לא מחייב."
