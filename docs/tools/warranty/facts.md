# שעון האחריות של חוק המכר: העובדות מנוסח החוק (HAD-527 turn 4, נשלף 14.10.2026)

מקור: חוק המכר (דירות), התשל"ג-1973, נוסח מלא בוויקיטקסט: https://he.wikisource.org/wiki/חוק_המכר_(דירות)

- סעיף 4(ג): "תקופת בדק" = התקופה הקבועה בתוספת, שתחילתה בעת העמדת הדירה לרשות הקונה. "תקופת אחריות" = שלוש שנים שתחילתן בתום תקופת הבדק.
- סעיף 4(א)(4): אי־התאמה יסודית (נשיאת המבנה ויציבותו): 20 שנה מהעמדת הדירה לרשות הקונה.
- סעיף 4א(א)(1): אי־התאמה שאפשר היה לגלות במסירה: להודיע תוך שנה מהמסירה. 4א(א)(2), 4א(ב): אחרת, תוך זמן סביר מהגילוי.
- סעיף 4ב: המוכר חייב לתקן תוך זמן סביר.
