# Aurelia master recipe — repository delivery

## Outcome

The complete Aurelia recipe package was assembled under `handoff/codex/2026-08-25-aurelia-master-recipe/` as a durable, agent-readable repository artifact.

It contains the isolated buyer-experience lab, the WordPress-compatible preview plugin, the project-page recipe, non-blocking checklist-light mechanism, SEO and intent specification, engineering/content BOM, code evidence, real public-source fingerprints, research, responsive browser evidence, operations manual, work log and downloadable ZIP artifacts.

## Product goal

Aurelia is not intended to remain a detached mockup. It is the controlled prototype used to prove the page recipe before implementing Aurelia as a real marketing project in WordPress and then applying the proven contract to the live premium project fleet.

## Repository-safety adaptation

This repository is public. Public HTML captures contained a browser-visible Mapbox token, transient nonces and public contact values. Those values were redacted while preserving the surrounding HTML, DOM, selectors and wiring. The standalone lab falls back to a real OpenStreetMap raster style when no Mapbox token is present; WordPress remains designed to receive its Mapbox token from existing localized runtime configuration.
