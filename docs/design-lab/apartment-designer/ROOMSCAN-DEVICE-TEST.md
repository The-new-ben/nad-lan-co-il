# מדידה במצלמה: בדיקה על טלפון אמיתי

הבדיקה הזאת **עוד לא נעשתה**. כל מה שנבדק עד עכשיו רץ במחשב, עם מכשיר מדומה (`roomscan-xrmock.js`) ועם דירות מחושבות (`test-roomgeom.mjs`). רק טלפון אמיתי יגיד אם המעקב של המצלמה, הסימון על הרצפה והעוגנים מתנהגים כמו בדמה.

## מה צריך
- טלפון אנדרואיד עם כרום מעודכן (רוב הטלפונים מ-2019 ואילך).
- דף שמחבר את הרכיב, בכתובת https (באתר עצמו, או בכתובת בדיקה מאובטחת). בכתובת http רגילה המדידה לא תיפתח.
- מטר מתקפל או מד לייזר, ודירה עם שלושה חדרים לפחות. אור טוב.

## מה לוחצים ומה אמור לקרות
1. פותחים את הדף. מופיע המסך "מודדים את הדירה במצלמה" עם שלושה צעדים. לוחצים "להתחיל מדידה".
   אמור לקרות: כרום מבקש אישור למצלמה (בפעם הראשונה), ואז רואים את החדר דרך המצלמה, עם פס לבן למעלה וכפתורים למטה.
2. מכוונים לרצפה ומזיזים את הטלפון לאט. אמור להופיע סימון עגול על הרצפה, והכפתור "פינה" נדלק.
3. מכוונים לפינה הראשונה של החדר, בדיוק על הקו שבין הקיר לרצפה, ולוחצים "פינה". ממשיכים מסביב לחדר.
   אמור לקרות: קו כחול על הרצפה בין הפינות, מרחק חי למעלה (למשל "3.42 מ׳"), ומפה קטנה בפינה עם אורכי הקירות באדום.
4. מכוונים שוב לפינה הראשונה. ההודעה למעלה אומרת "הסימון על הפינה הראשונה". לוחצים "סגירת חדר" ובוחרים שם.
5. דלת: לוחצים "דלת", מסמנים צד אחד של הפתח על קו הרצפה, ואז את הצד השני. אותו דבר עם "חלון" (מתחת לחלון, על קו הרצפה).
6. עוברים לחדר הבא בלי לצאת, מודדים אותו באותה דרך. כך גם את השלישי.
7. לוחצים "סיום". אמור להופיע "התוכנית מוכנה" עם התוכנית, מספר החדרים, השטח ושורת האמת על הדיוק.

## בדיקות קטנות בדרך
- "ביטול" מוחק את הפינה האחרונה. אחרי "סגירת חדר", "ביטול" פותח את החדר מחדש.
- מכוונים לשולחן: ההודעה "זה לא הרצפה" והכפתור לא מסמן את השולחן.
- מכסים את המצלמה ביד לשנייה: מופיעה ההודעה "הזיזו את הטלפון לאט, ליד משהו עם פרטים". אחרי שמורידים את היד, מה שנמדד עדיין שם.
- לוחצים "זווית ישרה" לכיבוי ומודדים קיר עקום בכוונה: הקו לא מתיישר.
- לוחצים בכפתור החזרה של אנדרואיד באמצע: המדידה נסגרת ומסך התוצאה מראה את החדרים שנסגרו.

## מדידת הדיוק (החלק החשוב)
מודדים עם מטר שלושה דברים, ורושמים ליד כל אחד את מה שהתוכנית מראה (בכלי השרטוט אחרי "להמשיך לתיקון ולתלת ממד", או במפה הקטנה):

| מה מודדים | מטר (ס״מ) | התוכנית (ס״מ) | הפרש |
|---|---|---|---|
| הקיר הארוך של הסלון, מפינה לפינה על קו הרצפה | | | |
| רוחב חדר שינה, מקיר לקיר | | | |
| עובי קיר בין שני חדרים, במשקוף של הדלת שביניהם | | | |
| (רשות) האלכסון של החדר הגדול | | | |

- הפרש של עד 3 עד 5 ס״מ בקיר של 4 מטרים: תקין למדידה במצלמה.
- הפרש של יותר מ-10 ס״מ: לרשום באיזה חדר, באיזה אור ובאיזו מהירות הלכו, ולשלוח צילום מסך.
- כדאי לחזור על אותה מדידה פעמיים, פעם לאט ופעם מהר, כדי לראות כמה זה משתנה.

## מה לרשום בסוף
דגם הטלפון, גרסת כרום, כמה זמן לקח (מופיע בתוצאה), כמה חדרים, טבלת הדיוק, וכל הודעה או מסך שנראו לא נכון.
