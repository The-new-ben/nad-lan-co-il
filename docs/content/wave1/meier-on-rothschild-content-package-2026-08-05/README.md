# Meier on Rothschild content-only package

This package contains four independently written, native-language long-form buyer articles and the evidence used to research and verify them.

## Start here

- `00-source-ledger.md`: frozen facts, dated price evidence, source conflicts, prohibited claims and the common source list.
- `01-live-google-intent-ledger.md`: real localized Google research in the connected Chrome browser for English, French, Russian and Arabic with Israel location.
- `02-qa-report.md`: final acceptance results, link checks, hashes and isolation evidence.
- `03-browser-source-verification.md`: direct Chrome checks for protected and high-risk public sources.
- `research-source-ledger-draft.md`: detailed source discovery and reconciliation notes.
- `existing-page-audit.md`: read-only audit of the current Hebrew page and all four language suffixes.
- `cultural-intent-support.md`: language-specific buyer needs, terminology and decision questions for a completed premium tower.
- `qa-en-ar-source-review.md`: pre-correction review that surfaced the height, apartment-count and Arabic evidence defects.
- `qa-en-fr-review.md`: independent French language and buyer-intent review.
- `qa-four-language-parity.md`: final-snapshot cross-language fact and source-parity review.

## Articles

- `meier-on-rothschild-en.md`
- `meier-on-rothschild-fr.md`
- `meier-on-rothschild-ru.md`
- `meier-on-rothschild-ar.md`

The articles share one fact base and the same S01-S20 source order, but each is written for the natural search intent and purchase questions of its audience. They distinguish current resale discovery from verified inventory, asking prices from completed transactions, and tower-level design from unit-specific rights, views, condition and operating costs. They also preserve the public 154-to-158-metre height conflict and the difference between the 147-apartment project figure and the later report of 100 apartments in practice, without presenting either apartment count as the current registered legal total.

Nothing in this package has been imported into WordPress. No live page, code, model, media, URL or existing project content was changed.
