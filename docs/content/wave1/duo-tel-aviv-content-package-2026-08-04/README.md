# DUO Tel Aviv content-only package

This package contains four independently written, native-language long-form buyer articles and the evidence used to research and verify them.

## Start here

- `00-source-ledger.md`: frozen facts, dated metrics, conflicts, prohibited claims and the common source list.
- `01-live-google-intent-ledger.md`: real Google Chrome research in English, French, Russian and Arabic with Israel location.
- `02-qa-report.md`: final acceptance results, link checks, hashes and isolation evidence.
- `research-source-ledger-draft.md`: detailed primary-source research and reconciliation notes.
- `existing-page-audit.md`: read-only audit of the current Hebrew project page and any existing language records.
- `cultural-intent-support.md`: language-specific buyer needs, terminology and decision questions.

## Articles

- `duo-tel-aviv-en.md`
- `duo-tel-aviv-fr.md`
- `duo-tel-aviv-ru.md`
- `duo-tel-aviv-ar.md`

Each article starts with publishing metadata, then one public H1 and the complete buyer article. The four versions share one verified fact base and one source order, but each is written for the needs and natural vocabulary of its own audience.

Nothing in this package has been imported into WordPress. No live page, code, media, URL or existing project content was changed.
