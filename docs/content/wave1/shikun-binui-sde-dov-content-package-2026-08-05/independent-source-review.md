## Conflicts with the live Nad-lan page

### Floor count

The live page repeatedly publishes a 38-storey tower. The current architect page publishes a 40-storey tower. Other discovery surfaces showed 39 and 42, but snippets are not evidence.

Decision: reject 38 as a locked fact. Attribute 40 specifically to the current architect page or omit the numerical floor count until approved permit drawings are directly readable.

### Current stage

The live page labels the project `בהיתר בנייה`, suggesting it is still in the permit stage.

Decision: stale and materially misleading. Official disclosures state that a full permit exists and structural works had begun by 10 February 2026. The current architect page lists the project as under construction.

### Exact permit date

The live page says the full building permit was received in December 2025.

Decision: not verified. The official evidence establishes only that a full permit existed by 10 February 2026. No directly readable primary source establishing a December 2025 issue date was found.

### Completion date

The live page says completion is expected in September 2028.

Decision: not verified. A focused Chrome search found no directly supporting source. Treat the contractual delivery or occupancy date as unpublished.

### Low-rise building floors

The live page says there are two additional eight-storey buildings.

Decision: the current architect page confirms two contextual buildings but does not publish their floor count. Reject the number eight unless it is verified in an approved, readable current plan.
