# YOO Tel Aviv multilingual content package

Content-only delivery for four new language posts. This package does not modify the existing Hebrew post, WordPress, templates, code, media, URLs, canonical tags or hreflang output.

## Public article files

- `yoo-tel-aviv-en.md`
- `yoo-tel-aviv-fr.md`
- `yoo-tel-aviv-ru.md`
- `yoo-tel-aviv-ar.md`

Each article is a native buyer guide rather than a literal translation. The four versions share one locked fact ledger and one source order while changing the decision emphasis for the intended readership. Each article contains one H1, the nine required H2 sections, more than 5,000 words before Sources, visible FAQs, conditional image-alt suggestions, the four required contextual internal links and one independent-site statement.

## Publishing fields

`publishing-fields.md` contains the exact suffix slug, title, H1, native meta description, direction and article filename for each language. The Arabic post is marked RTL. No manual canonical or hreflang value is included because the existing platform derives that relationship from the language suffix.

## Research and evidence

- `00-source-ledger.md` is the shared fact ledger. It separates verified facts, historical claims, narrow transaction evidence, planning context, conflicts and unpublished fields.
- `01-live-google-intent-ledger.md` records real Google Chrome research in English, French, Russian and Arabic with Israel targeting.
- `cultural-intent-support.md` turns the observed language-specific searches into four editorial briefs without treating search snippets as project facts.
- `03-browser-source-verification.md` records browser verification of the source set and important limitations.
- `existing-page-audit.md` records the live Hebrew page and missing suffix-page observations. It is diagnostic only and authorizes no site changes.
- `02-qa-report.md` records the final structural, factual, language, link and source-parity gates.
- `qa-four-language-parity.md` is the independent final read-only comparison of all four public articles.

## Locked editorial boundary

YOO Tel Aviv is treated as a completed and occupied resale complex in Park Tzameret, not a new Sde Dov project and not a live developer launch. Historical documents describe an original plan of up to 297 apartments and towers of 41 and 37 above-ground floors, while other public records count floors differently. The articles preserve that conflict. They do not invent a current apartment count, inventory, project-wide price list, management fee, address-to-tower mapping, view, delivery date or exact coordinates.

The one dated transaction example and the one reported apartment dispute remain narrow evidence about the identified apartment or event. Neither is converted into a current project-wide price, defect claim or forecast. Planned transport and school information is described without operating-date, walking-time, catchment or admission promises.
