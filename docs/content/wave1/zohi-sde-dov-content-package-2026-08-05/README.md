# ZOHI Sde Dov multilingual content package

Content-only delivery for four new language posts. This package does not modify the existing Hebrew post, WordPress, templates, code, media, URLs, canonical tags or hreflang output.

## Public article files

- `zohi-sde-dov-en.md`
- `zohi-sde-dov-fr.md`
- `zohi-sde-dov-ru.md`
- `zohi-sde-dov-ar.md`

Each article is a native buyer guide rather than a literal translation. English, French, Russian and Arabic use one locked fact contract while answering the buying questions observed in each language's live Google results.

## Publishing fields

`publishing-fields.md` contains the exact suffix slug, project-first Title, H1, native meta description, direction and article filename for every language. Arabic is marked RTL. No manual canonical or hreflang value is included because the existing platform derives the relationship from the suffix slugs.

## Locked current project boundary

ZOHI is a residential project in Sde Dov, Tel Aviv. The current official project site publishes 230 apartments, a mix of 2 to 6 rooms plus penthouses, 3 metre ceiling language, a private urban garden of about 2.8 dunams, shared workspaces, a gym, a yoga area and a residents' lounge. It credits Galor Fishbein Architects and presents Tal Goldschmidt Fish in connection with architecture and interior design.

The official project presentation identifies Levinstein, Metropolis and Mivne. It describes Metropolis as leading Allied Real Estate's residential arm. Levinstein listed ZOHI in its marketed-project category on the research date.

Current first-party material did not publish a unit price list, current availability, contractual delivery date, current permit status, current construction progress, current numerical building configuration or unit schedule. Those gaps remain explicit in every language.

## Dated history kept separate

The package does not merge two different historical configurations. Globes reported a four-building planning version on 27 August 2024. Mako reported a different three-building launch configuration, launch price range, early-marketing payment structure, works statement and occupancy forecast on 28 January 2026. Every use of those claims retains its date and attribution. None becomes a current offer, current stage, current specification or contractual promise.

The current official mix of 2 to 6 rooms plus penthouses controls over the older launch mix. The current official garden wording of about 2.8 dunams controls over the launch report's rounded description of about 3 dunams.

## Excluded claims

The articles do not publish the planning lot as a postal address, an unsupported 12-floor configuration, demonstration apartments as inventory, unsupported price estimates, current 20/80 terms, current construction or permit status, contractual delivery, guaranteed sea view, measured sea distance, or a pool as a current first-party amenity.
