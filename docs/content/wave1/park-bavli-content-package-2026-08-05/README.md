# Park Bavli multilingual content package

Content-only delivery for four new language posts. This package does not modify the existing Hebrew post, WordPress, templates, code, media, URLs, canonical tags or hreflang output.

## Public article files

- `park-bavli-en.md`
- `park-bavli-fr.md`
- `park-bavli-ru.md`
- `park-bavli-ar.md`

Each article is a native buyer guide rather than a literal translation. The four versions use one locked fact base and one 14-source order while changing the decision emphasis for English, French, Russian and Arabic readers. Every article contains one H1, the nine required H2 sections, more than 5,000 words before Sources, visible FAQs, conditional image-alt suggestions, the four required contextual internal links and one independent-site statement.

## Publishing fields

`publishing-fields.md` contains the exact suffix slug, title, H1, native meta description, direction and article filename for each language. Arabic is marked RTL. No manual canonical or hreflang value is included because the existing platform derives the relationship from the language suffix.

## Locked entity boundary

The official project-brand source is `parkbavli.co.il`. The similarly named `.com` domain resolved to a parked `/lander` page and is excluded. Broader Bavli-Dekel planning figures and the separately branded Beresheet Bavli and Masterpiece Bavli projects are not attributed to Park Bavli.

The strongest municipal fact set belongs to Tower 1: HaRav Nissim 9, plan 1770A, 44 storeys and 153 units after a 2022 approved combination of two existing units. A January 2025 Ynet report described two 44-storey towers and about 340 apartments in its dated transaction context. These scopes are not added together and neither becomes current 2026 inventory.

The reported approximately NIS 43 million penthouse sale remains one exceptional, dated transaction involving a roughly 360-square-metre built area, about 145 square metres of terraces and floor 44 of the second tower. It is not converted into an average, starting price or general price per square metre.

Current project-wide inventory, asking-price list, unit mix, management charges, delivery status, parking, storage, safe-room specification and view remain unpublished or apartment-specific. The articles direct buyers to obtain and verify these details for the exact tower and unit.
