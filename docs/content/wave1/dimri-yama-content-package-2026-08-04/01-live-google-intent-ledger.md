# DIMRI YAMA - live Google Chrome intent ledger

Research date: 2026-08-04

Research surface: the user's connected Google Chrome browser. Searches were run on Google with `gl=il`, language-specific `hl`, `pws=0`, and `lr=lang_ru` or `lr=lang_ar` when language restriction was useful. The search location shown by Google was Tel Aviv, determined by IP. This is a recorded localized sample, not a universal ranking distribution.

Page role: one project profile for buyers considering DIMRI YAMA in Sde Dov, Tel Aviv. It must not own broad city-guide, tax-guide, mortgage-guide or investment-guide intent. Those questions are answered only as they affect a project purchase and link to the appropriate site tools or guides.

## Cross-language SERP conclusions

- The project name itself has the strongest clean Google footprint in English and French.
- The French SERP already showed the existing nad-lan French URL. That is evidence of an existing page, not permission to edit it in this content-only task.
- The Russian and Arabic project-name samples did not surface a strong dedicated DIMRI YAMA result from nad-lan. This increases the need for a clear project-first H1 and opening but does not prove an indexing defect.
- Google did not expose a stable People Also Ask block in the captured project queries. No PAA questions are invented.
- Search phrases guide title and topical coverage. They are not density targets and will not be repeated mechanically.
- Every language will carry the same verified project facts. Cultural adaptation changes sequence, examples, vocabulary and practical questions, never the underlying numbers.
