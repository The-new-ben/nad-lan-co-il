## חוקי הבעלים לבניין הזה (הסטנדרט החדש)
1. הבנה במבט אחד; שפה חזותית; אריחים ולא טקסט.
2. כפתור הגדלה-למסך-מלא (סגנון יוטיוב) על הנוף מהחלון ועל שרטוט המעצב; מזעור חזרה.
3. מרחיבים את שטח התצוגה — לא דוחסים.
4. סיור הרחפן = אדפטציה של כלי הארת' הקיים (היום צולל לרחוב — צריך ריחוף גבוה מתויג,
   "מסוק המיליונרים"), + תיקון בעיית ה-API.
5. שני הסרטונים הקיימים (הראשי + זה ליזמים) משולבים בעמוד.
6. המפה מתחת לתצוגה עם האלומה — קודש, לא נוגעים; קשורה להוטספוטים ולדירות הזמינות.
7. מתקנים לחיצים: בריכה / חדר כושר / ספא — נבחרים בחוויה.
8. חלוקת התוכן: אני אוסף את כל הנתונים המדויקים (רמת קומפס/זילו); הכתיבה הגדולה
   (5,000 מילים × 5 שפות) = פרומפט ל-ChatGPT של הבעלים → ZIP → אני מטמיע.
9. צילומי מסך אמיתיים בכל שלב; השוואת מתחרים; מצב אלוהים+ביקורתי.
10. בסוף: הבעלים פונה לחג'ג' עם הלידים מהאזור + טופס הזנת כל הפרויקטים שלהם.
