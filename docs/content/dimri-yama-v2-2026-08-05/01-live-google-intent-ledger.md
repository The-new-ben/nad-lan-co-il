# DIMRI YAMA - live localized Google intent ledger

Research date: 2026-08-05

Research surface: the user's connected Google Chrome browser, not a synthetic keyword database. Each main query was run on Google with Israel selected through `gl=il`, the target-language interface through `hl`, and personalization reduced with `pws=0`. Google showed Tel Aviv or Tel Aviv-Yafo as the local area from the Israeli connection. Results are a dated local sample. They do not prove national search volume or a fixed ranking order.

Research sequence: the facts were frozen first, then one focused Google results query was inspected for each language. English and French autocomplete were also opened visibly in Chrome. Russian and Arabic keyword evidence was taken from native query wording and visible result titles because their later autocomplete views did not return a stable native suggestion panel. No missing suggestions or People Also Ask questions were invented.

Page role: a project profile for buyers considering DIMRI YAMA in Sde Dov, Tel Aviv. It may answer tax, mortgage, relocation and investment questions only where they affect the project decision. Broad city, tax and mortgage intent belongs to the linked NadLan guides and calculators.

## Cross-language decisions

- Each URL owns one primary purchase intent and uses the exact selected phrase in its SEO title and H1.
- The four articles carry the same frozen project facts. Language changes emphasis, examples and vocabulary, not numbers, dates or evidence status.
- Result titles often use sea-view language. The articles reject any apartment-specific sea-view claim without plan, orientation, height and obstruction evidence.
- Google did not expose a stable People Also Ask block in the four captured result pages. No PAA questions were added as if observed.
- Search phrases are relevance signals, not repetition targets. They appear naturally and do not replace the project name, verified facts or buyer questions.
- Images are not part of this package. The metadata supplies ten conditional alt suggestions per language for later use only when each text accurately describes the selected image.
