# תל אביב מתכננת

חבילת אתר סטטי מקורית בעברית על פרויקטים, שכונות ותשתיות בתל אביב-יפו.

## פתיחה
פתחו את `index.html` בדפדפן, או העלו את כל התיקייה לאחסון סטטי.

## מה כלול
- 16 עמודי ליבה לפי האינדקס העירוני שנבדק ביום 2026-08-18.
- 3 מדריכי הקשר.
- 20 איורים מקוריים בפורמט SVG ו-PNG.
- קובצי JSON ו-CSV, מטא-דאטה, מפת אתר ודו״ח בדיקות.

## לפני פרסום
1. החליפו את `https://example.org/tel-aviv-projects` בכתובת האמיתית בכל קובצי HTML, ב-sitemap וב-robots.
2. בדקו מחדש סטטוס, מספרים ותאריכים במקורות.
3. שמרו את ההבהרה שהאתר עצמאי ואינו אתר עירוני רשמי.
4. אל תציגו את האיורים כתשריט, מפה או הדמיה מאושרת.

## רישוי ותוכן
הטקסטים והאיורים בחבילה נוצרו מחדש. מקורות חיצוניים מקושרים לצורכי אימות. אין בחבילה עותקים של תמונות העירייה, לוגו או קבצי מקור עירוניים.
