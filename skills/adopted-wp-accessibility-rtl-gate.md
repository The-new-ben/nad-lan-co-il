# Adopted WordPress Accessibility And RTL Gate Skill

> Accessibility, mobile, and RTL Hebrew gate for NadLan public screens, admin war room, showroom controls, forms, and listings.

## When to use this

- Any UI, form, navigation, card, modal, drawer, map, 3D control, or admin table changes.
- Any Hebrew or English language switch work.
- Any mobile layout changes.

## Gate

1. Keyboard access for buttons, cards, tabs, drawers, and close controls.
2. Visible focus state.
3. Touch target size suitable for mobile.
4. Labels for inputs and controls.
5. Correct RTL for Hebrew and LTR for English.
6. No text overflow at 390px.
7. No horizontal scroll.
8. Contrast checked against the active cream tokens.
9. No technical labels exposed to buyers.

## NadLan adaptation

The showroom must work for buyers and foreign investors on mobile first. Fancy 3D does not count if the contact flow, unit selection, and language direction fail at 390px.
