# Skill: Knowledge Capture Protocol (owner standing rule)
Every build, fix, research, or operational run on ANY site MUST end with a skill capture:
1. If a reusable pattern emerged -> write/update a skills/skill-*.md (what, why, exact steps,
   traps hit, code locations).
2. If research was done -> the cited doc goes in docs/ AND its actionable distillation goes into
   the relevant skill file.
3. Cowork/Codex runs: the final report includes a "SKILLS LEARNED" section; Claude commits them.
4. Skills are written site-agnostic (placeholders for site name/URLs) so they port to the next
   website (Justice legal portal and beyond) by copy.
