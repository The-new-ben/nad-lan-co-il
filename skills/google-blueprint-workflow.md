# Google Blueprint workflow

> **This content was folded into `strategy-master.md` §13 on 2026-05-30** per owner request. Read it there.

The Blueprint is the 7-step manual SERP reverse-engineering process used before writing any article: choose query → manual Google search in Hebrew (top 10, PAA, related, featured snippet) → derive intent → pattern-match (shared backbone, differentiators, gaps) → numbers with primary sources → ChatGPT prompt → hand off to publishing.

For the matching publishing protocol (what to do once ChatGPT returns the HTML), see `internal-linking-hub-spoke.md` §"Article publishing protocol".
