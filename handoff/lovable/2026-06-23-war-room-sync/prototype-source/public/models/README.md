# Models

`rainbow.glb` is loaded dynamically by `<model-viewer>` in the Showroom for
the Rainbow Tower project (`asset_state: "real-glb"`). In this prototype the
file is intentionally left out of the repo to keep it light — drop the real
GLB here (the WordPress repo ships an 832 KB `Rainbow Tower/model.glb` we can
mirror in the next sync run) and the viewer picks it up with no code change.
