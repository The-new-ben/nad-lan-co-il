# 05 Branding Favicon Social

## Wordmark

Keep NadLan3D for now.

Construction:

- NadLan in Frank Ruhl Libre 500 or Fraunces 500 for English contexts.
- 3D in Heebo or Inter Tight 700.
- 3D is smaller, gold, and raised above the baseline.
- No cube icon. No generic house roof. No purple technology mark.

## Logo spacing

Desktop header:

- Wordmark font size: 30px.
- Gap between word and 3D: 7px.
- 3D size: 54 percent of wordmark.
- Header height: 76px.

Mobile header:

- Wordmark font size: 25px.
- Header height: 64px.

## Favicon

Files created in this packet:

- `screenshots/favicon-32.png`
- `screenshots/favicon-192.png`
- `screenshots/apple-touch-icon-180.png`

WordPress placement:

- Upload icon files to the active theme or plugin assets directory.
- Set site icon in WordPress admin if possible.
- Also add explicit link tags if the plugin controls the head.

Example:

```html
<link rel="icon" sizes="32x32" href="/wp-content/uploads/nadlan3d/favicon-32.png">
<link rel="icon" sizes="192x192" href="/wp-content/uploads/nadlan3d/favicon-192.png">
<link rel="apple-touch-icon" sizes="180x180" href="/wp-content/uploads/nadlan3d/apple-touch-icon-180.png">
```

## What not to do

- Do not use a random 3D cube logo.
- Do not use a skyline as the brand mark.
- Do not put the logo in a pill.
- Do not make the favicon a tiny full wordmark.
