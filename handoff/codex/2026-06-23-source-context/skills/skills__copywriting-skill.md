# Copywriting Skill — Hebrew voice for nad-lan.co.il

> **Notice to all agents:** Hebrew is the production language. Every public page goes through this skill before publishing. Codex and Antigravity generating content: read this first, every time.

## 1. Audience voices

- **קונה לדירה ראשונה**: סבלני, מסביר, אמפתי. דוגמה: "תהליך קניית דירה ראשונה ארוך מהצפוי. ריכזנו את כל מה שצריך לדעת, לפי הסדר."
- **מוכר**: עיוני-פיננסי. דוגמה: "תמחור נכון של דירה הוא ההבדל בין שלושה חודשים לשנה על המדף."
- **משקיע**: ענייני, ממוקד תשואה ועלויות. דוגמה: "תשואת שכירות ברוטו ממוצעת בבאר שבע: 5.2%. ניכוי הוצאות והכרסום של תפוסה מביא לנטו של כ-3.8%."
- **תושב מתעניין**: סקרני. דוגמה: "השכונה נחשבת לאחת הצומחות בעיר; מחיר המ"ר עלה ב-23% בחמש השנים האחרונות לפי נדלן.gov.il."
- **דייר בבניין לתמא 38 / פינוי-בינוי**: זהיר, רוצה להגן על זכויותיו. דוגמה: "החתימה על הסכם תמא 38 קושרת את הדירה שלך לפרויקט לשנים ארוכות. לפני שחותמים, יש מה לבדוק."

## 2. Hebrew writing rules

- עברית מדויקת. לא תרגום מאנגלית.
- ללא קווים מפרידים ארוכים (em dash). השתמשו ב"," ו"–" קצר רק במידת הצורך.
- כתיבה ישירה. לא "במאמר הזה נסקור", לא "לסיכום", לא "כפי שראינו".
- מספרים תמיד עם מקור: "לפי נדלן.gov.il, ינואר 2026".
- אל תצטטו נתון של מתחרה. נתונים פתוחים בלבד (gov.il, למ"ס), עם תאריך.
- אל תבטיחו "הזולה ביותר", "המתקדם בישראל", "התשואה הגבוהה ביותר". כל הבטחה כזו פוגעת בכל הציטוטים האחרים.

## 3. Forbidden phrases (סימני AI — אל תכתבו)

- "חשוב להבין"
- "ראוי לציין"
- "במילים אחרות"
- "מצד אחד...מצד שני" (כפסקה שלמה)
- "עולם הנדלן"
- "בעידן הנוכחי" / "בעידן הדיגיטלי"
- שלוש שאלות רטוריות ברצף
- "אכן" / "בהחלט" / "ללא ספק" כפותחים
- "בעולם שבו..."
- ישנם אינסוף סיבות לכך / "אינסוף" כתואר
- "באופן כללי" כפתיחת פסקה
- "בסופו של דבר" כפסקה אחרונה

## 4. Forbidden phrases (מילים פנימיות — אסור בעמוד ציבורי)

לעולם לא יופיעו בקופי שמופנה למשתמש:

- ליד / leads / לכידת ליד
- CRM / סוכן / ספק / supplier
- פילר / spoke / hub / cluster / נישה
- intent / כוונה (במשמעות SEO)
- money page / מילת מפתח / KD
- UTM / tagging / campaign / utm_*
- attribution / מודל הכנסה / פיצול הכנסות
- "תוכן SEO" / "מאמר ממומן" / "תוכן שיווקי"

Codex: לפני שמירת עמוד, חפש את הרשימה הזו ב-grep. כל התאמה = עצור ושלח להחלטת הבעלים.

## 5. H1, Title, Meta patterns

- H1: `{נושא} — {הבטחה ענייניית}`. דוגמה: "קניית דירה ראשונה — שלבים, מסים ועלויות נסתרות".
- Title (≤60 תווים): `{H1 מקוצר} | nad-lan`
- Meta description (150-160 תווים): פתיח עובדתי + מה הקורא יקבל + CTA קצר. דוגמה: "תהליך קניית דירה ראשונה ב-2026: מס רכישה לדירה יחידה, ערבות חוק מכר, רישום בטאבו. מדריך מלא + מחשבון."

## 6. CTA wording — public

Allowed:
- "התחילו חיפוש"
- "פתחו את המחשבון"
- "קבלו הערכת שווי"
- "ייעוץ ראשוני בחינם" (15 דקות, מותנה באישור לשכת עו"ד — ראה `monetization-lawyer-angle.md`)
- "השאירו פרטים ונחזור אליכם בתוך יום עסקים"
- "עיינו בעסקאות אמיתיות באזור"

Forbidden:
- "השאר ליד"
- "הירשמו עכשיו לפני שיהיה מאוחר"
- "מבצע מוגבל"
- "האזור החם של 2026" (אלא אם זה תוצאה של נתון מקור עם תאריך)
- "אל תפספסו"
- "[שם השכונה] בלעדי" / "רק כאן תמצאו"

## 7. Image alt text rules

- מתאר את התמונה, לא את העמוד. "מחשבון משכנתא" אינו alt לתמונה של אדם עם מחשבון; "אדם יושב מול שולחן עם מחשבון משולחני ומסמכים" הוא alt.
- בעברית.
- 5-15 מילים.
- ללא keyword stuffing.

## 8. Author by-line for legal/tax content

חובה בכל מאמר תחת `/tax-legal/`, `/urban-renewal/`, או כל מאמר שמטפל בחוזה, מס, או הליך משפטי:

```
מאת [שם הבעלים המלא], עורך דין · נבדק לאחרונה: {YYYY-MM-DD}
```

מתחת לבייליין, פסקה תחתונה קבועה:

> אין לראות במאמר זה ייעוץ משפטי. כל מקרה דורש בדיקה פרטנית של נסיבותיו. ליצירת קשר לייעוץ ראשוני: [קישור].

ראה `yoast-config.md` סעיף Person schema כדי לוודא שהמטא-דאטה מסונכרנת.

## 9. Numbers and currency

- שקל: `1,978,745 ₪` (פסיקים, סימן ₪ אחרי, ללא רווח דק).
- אחוזים: `8%` (לא `8 %`).
- שנים: `2026` בלבד, לא "תשפ"ז" ולא "השנה".
- תאריכים: `2026-01-15` או `15 בינואר 2026`. לא "15/1/26".
- טווחים: `1,978,745–2,347,040 ₪` (עם en dash קצר, לא em dash, לא "עד").

## 10. Reading-level target

עברית ברורה לקוראים שאינם מומחים. רמת קריאה: בוגר תיכון. מאמר משפטי יכול להיות יותר טכני אם מובא הסבר נלווה.

## Em-dash ban — enforced 2026-05-29 (owner-explicit)

**Never** use the em-dash `—` (U+2014) in user-facing copy on nad-lan.co.il. Owner-explicit. Use ` - ` (regular hyphen with surrounding spaces), comma, or colon depending on context. Hebrew rhythm allows the comma in 80% of cases.

When you write new content or generate widgets, **scan for `—` before publishing**. To clean an existing file in the repo:
```
python3 -c "s=open('FILE').read(); open('FILE','w').write(s.replace(' — ',' - ').replace('—',' - ').replace('  -  ',' - '))"
```
