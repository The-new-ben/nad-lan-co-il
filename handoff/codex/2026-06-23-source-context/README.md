- Rainbow is the best technical reference: real model, poster, plans, unit map, environment data, hotspots, and camera orbit values.
- Dimri has better sales/story material but lacks a real approved GLB. Treat it as concept/facade fallback unless new assets are supplied.

- Showroom UX must be mobile-first: no horizontal overflow, no nested scroll traps, no fake facades, no fake maps.
- Use model/facade/map/tour asset truth:
  - real GLB -> model-first
  - official/concept facade -> labeled facade-first
  - missing asset -> premium missing-state and contractor asset intake
  - missing Mapbox token/data -> designed not-ready map state
- The listing arm should exist but should not dominate the first public hierarchy until inventory is strong. Lead with premium projects, 3D/project showroom, investor confidence, foreign-buyer/investor support, and professional trust.
- SEO scope is full-market, not leftovers: projects, listings, professionals, guides, city/neighborhood hubs, foreign buyers into Israel, and Israelis investing abroad.
- Outbound investor markets now required: Cyprus, Dubai/UAE, Greece, Thailand, plus additional justified markets.
- Brand/name is not final. Older docs use "Nadlan Chacham"; the owner says that name appears occupied. Treat older branding as design DNA, not a final name.
- WhatsApp/call/AI contact must be one polished contact system, not random floating buttons.
- Multilingual path from prior research favors Polylang Pro, translated strings in PHP, shared language-neutral unit JSON, and `/en/`, `/fr/`, `/ru/` style subdirectories.
- Anti-cannibalization is central: listing/unit pages support project and money hubs; unit-level pages should not compete with hub pages unless they have unique value.
