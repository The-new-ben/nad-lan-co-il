# Aurelia — בדיקת האתר החי, מפרט תיקון וחבילת מתקנים

## פסק הדין

העמוד החי אינו מוכן לשמש עדיין כמתכון הקאנוני לכל פרויקטי NadLan. הוא מכיל יכולות אמיתיות וטובות — 320 יחידות, תוכניות, מודל GLB, מפת Mapbox ואלומת כיוון שמגיבות ל־`unit_id`, סטודיו וזרימת RFP — אבל החיבורים ביניהן מפוצלים בין שתי שכבות בחירה, שתי תצוגות כרטיס, קוד inline שאינו בריפו וגרסאות JS/CSS/payload שעלולות להתערבב בגלל cache שנתי.

הכשל הקשה ביותר אינו אסתטי: דפדפן יכול להריץ selected-unit חדש מול CSS ו־flags של legacy. לכן פעולה שעובדת אצל משתמש אחד יכולה להיות קטנה, מוסתרת או לא נגישה אצל אחר. לפני ליטוש עיצובי צריך להחזיר בעלות אחת על runtime, state וגרסת assets.

לא בוצע שום שינוי באתר החי, לא נשמר פוסט, לא הותקן תוסף, ולא נשלח טופס או ליד. החבילה היא מסירת מחקר, ראיות, קוד reference, נכסים ומפרט תיקון שנועד לעבור review לפני הטמעה.

## מה יש בחבילה

- `01-EVIDENCE/` — fingerprint יציב של ה־HTML הציבורי, שתי משיכות אימות זהות, צילום חוזה האדמין ללא nonces, 56 ממצאים, מטריצת קליקים וצילומי 320px.
- `02-SPEC/` — רוסט מלא, סדר עמוד, מפרט מיקרוסקופי, מסלול הדירה, מתקנים, SEO ו־Source.
- `03-DATA/` — 737 נורות אטומיות לא־חוסמות, חוזה 12 מתקנים ונתוני ההפעלה שלהם.
- `04-ASSETS/` — 12 פנורמות 2:1 נפרדות למתקנים, כולן בשפה אדריכלית אחת, עם hashes.
- `05-CODE/` — excerpts מדויקים מהקוד הקיים, baseline לשינויי קוד, state store אחד ו־renderer reference למתקנים.
- `06-WORDPRESS/` — תכנית הטמעה, שדות, migration, importer, versioning ו־rollback.
- `07-RESEARCH/` — benchmarks בינלאומיים ומסקנות מוצר/קוד.
- `08-BACKLOG/` — סדר תיקון לפי ממצא, בעלות קוד וראיה נדרשת.
- `09-DECISIONS/` — יומן עבודה, החלטות וביקורת עצמית.
- `scripts/` — מחולל החבילה, fingerprint ציבורי ואימות שלמות.
- `downloads/` — שתי מסירות 2026-08-25 המקוריות, כדי שהחבילה החדשה תהיה מצטברת ולא תאבד עבודה קודמת.

## חמשת הדברים הראשונים לצוות הפיתוח

1. להוציא כל asset ציבורי בשם content-hashed או להעלות `ver` בכל שינוי. אין להגיש קוד משתנה לשנה תחת אותו URL.
2. לבטל את דריסת `document.title` ב־`engine.js:218-232`; כותרת השרת/Yoast היא הבעלים.
3. לבחור selected-unit runtime יחיד. JS, CSS וה־payload חייבים לקבל אותו manifest/flag באותה תגובה.
4. לבטל את שכבת Aurelia inline שמסתירה 320 hotspots ומייצרת שישה אחרים; להחזיר selection owner יחיד עם `unit_id` אחד.
5. לתקן את מסלול המובייל כך שבחירה מציגה את אותה יחידה במסך הנוכחי, בלי להסתיר את הבניין, וממנה עוברים לתוכנית → מפה ואלומה → מראה → סיור → חזרה.

## הפעלת הבדיקות המקומיות

מתוך שורש הריפו:

```powershell
node handoff/codex/2026-08-26-aurelia-live-qa-remediation/scripts/build-package.mjs
node handoff/codex/2026-08-26-aurelia-live-qa-remediation/scripts/verify-package.mjs
```

בדיקת Source ציבורי עצמאית:

```powershell
node handoff/codex/2026-08-26-aurelia-live-qa-remediation/scripts/public-source-fingerprint.mjs https://nad-lan.co.il/projects/aurelia/
```

ה־hash להשוואה הוא `canonicalSha256`, לא ה־raw hash. האלגוריתם מסיר רק ערכים מסתובבים/פרטי קשר מוגדרים ואינו מנרמל HTML, רווחים או ירידות שורה. שתי משיכות האימות המצורפות החזירו `490124` תווים ואת אותו hash: `7dc8375e5408535eab85d8f92d97cc3b23e30d27b98c53efbe5533d087bcb0de`.

## פתיחת מעבדת המתקנים

לחיצה על `START-FACILITIES-REVIEW.cmd` מפעילה שרת מקומי ב־`http://127.0.0.1:4317/`. המסך טוען את 12 סצנות ה־360 ב־Pannellum ומציג את המפרט שלהן. זה review module נפרד, לא שינוי WordPress ולא תחליף למודל/מפה/אלומה.

## הגדרת “ירוק”

הנורות אינן חוסמות שמירה או פרסום. ירוק הוא ראיה, לא נוכחות שדה:

- פעולה אינטראקטיבית: קליק מוצלח ב־320, 390 ו־1440 עם צילום/DOM/result.
- Source: תגובת HTML ציבורית, hash וערך שנצפה.
- נכס: קובץ/URL, MIME, מידות ו־SHA-256.
- data: נתיב שדה, ערך צפוי וערך בפועל.
- ידני: בעלים, תאריך וראיה מצורפת.

DOM שקיים אך מוסתר, כפתור שמציג טקסט בלי פעולה, או תוצאה שעובדת רק במעבדה אינם ירוקים.
