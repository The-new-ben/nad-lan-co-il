# Aurelia — מתכון־העל לעמוד פרויקט

זוהי חבילת המסירה הקאנונית של Aurelia: פרויקט הדגמה מלא בשדה דב, מתכון מדויק לעמוד פרויקט, צ׳ק־ליסט נורות, BOM, מפת SEO ואינטנט, חוזה נתונים, קוד חיבור ל־WordPress, מחקר, Source fingerprints, ראיות בדפדפן, הוראות הפעלה ויומן החלטות.

המטרה אינה להשאיר דמו נפרד. Aurelia נועד להפוך, לאחר בדיקת preview ואישור, לפרויקט שיווקי אמיתי בתוך NadLan ולשמש כתבנית שממנה מאחדים בהמשך את Rainbow, DO, Dimri Yama, Ashira ושאר פרויקטי התלת־ממד.

## מה יש בחבילה

- מעבדת רוכש עצמאית עם בניין תלת־ממד, 320 יחידות, hotspot/בחירה, כרטיס דירה, תוכנית, מפה ואלומת כיוון, מראה מהחלון, סיורי פנים, מתקנים, סביבת הפרויקט, סטודיו, שיחת יזם ותהליך התקדמות.
- 138 בדיקות בסיס ב־17 תחומים, 9,098 מקרי מטריצה ו־536,000 צעדי replay למסלול בחירת הדירה.
- צ׳ק־ליסט נורות ירוקות, צהובות, כתומות ואדומות שאינו חוסם עריכה או פרסום.
- BOM הנדסי ותוכני: מערכות, מכלולים, רכיבים, תוכניות, תמונות, נתוני יחידה, מתקנים, תפעול ותוכן שיווקי.
- מפת SEO ואינטנט, סדר עמוד, מיקום רכיבים, מרווחים, CTA, schema, breadcrumbs, H1, snippet ו־source audit.
- תוסף preview נפרד ל־WordPress וחוזה נתונים משותף. התוסף אינו מחליף את `nadlan-config` ואינו מותקן באתר החי.
- קוד המקור שנשמר מהפרויקטים החיים, מטריצת הראיות, מחקר בחירת יחידה והשוואת מימושים.
- צילומי מסך, דוחות בדפדפן, קובצי בדיקה, raw public source מחוטא ו־SHA-256 manifest.

## שני מסלולים, חוזה אחד

`01-DEMO-LAB` הוא מעבדה עצמאית לבדיקת חוויית הרוכש והמתכון לפני WordPress. `02-WORDPRESS-COMPATIBLE` הוא מסלול preview שמחבר את אותו `unit_id`, אותן יחידות ואותם אירועים למערכת הקיימת. אין תלות טכנית בין שרת הדמו לבין WordPress, אך אסור להם לסטות בחוזה הנתונים.

## הפעלה מהירה של המעבדה

פתחו את `01-DEMO-LAB/START-DEMO.cmd`, או הריצו שרת קבצים מקומי מתוך `01-DEMO-LAB` ופתחו את `index.html`. עותק הריפו הציבורי אינו מכיל טוקן Mapbox: המעבדה משתמשת אוטומטית בשכבת OpenStreetMap אמיתית ללא מפתח. ב־WordPress המפה ממשיכה לקבל את טוקן Mapbox מההגדרה הקיימת של האתר, לא מהקוד בריפו.

## מצב מוכח

- בדיקות נתונים: 22/22.
- בדיקות DOM לאחר replay: 24/24.
- fingerprints של הקוד: 20/20.
- תצוגות שנבדקו: 1440×900, 390×844 ו־320×720.
- עותק הריפו המחוטא נבדק מחדש בדפדפן: hotspot `aur-t-29-b` שמר את אותו `unit_id`, עדכן את תווית המפה ואת אלומת הכיוון, הציג 14 markers, נשאר ללא overflow וללא שגיאות console.
- 320/320 עוגנים סמנטיים קיימים במודל.
- תוסף preview: נבנה ונבדק סטטית, אך עדיין לא הותקן ב־WordPress.
- בחירת mesh מדויקת לפי `UNIT_PICK_*`: עדיין צהובה עד שיוזן GLB/BIM עם meshes ברמת יחידה. ה־adapter לעוגנים הסמנטיים קיים.

## הדרך לפרויקט אמיתי

1. מתקינים את תוסף ה־preview רק בסביבת preview ומקשרים אותו לפוסט בדיקה.
2. מריצים את מסלול `unit_id` המלא במובייל ובדסקטופ ומצלמים Source ציבורי חדש.
3. מתקנים כל נורה שנשארה צהובה/כתומה בלי להחליף יכולת קיימת ב־CSS מדומה.
4. מאשרים תוכן שיווקי, שפות, מלאי, תוכניות, מתקנים, מחירים מוערכים ו־CTA.
5. רק לאחר אישור משלבים את החוזה והמימוש הקאנוני ב־`nadlan-config` ובונים פרויקט Aurelia אמיתי.
6. לאחר הוכחת התוצאה מעבירים את אותו מתכון לפרויקטים החיים, אחד בכל פעם, עם diff ו־Source fingerprint.

## אבטחת הריפו הציבורי

הראיות נשמרו, אך טוקנים, nonces, כתובות דוא״ל ומספרי טלפון שנדפסו ב־HTML הציבורי הוחלפו בסימוני `REDACTED`. השינוי אינו מוחק DOM, selectors, wiring או מבנה קוד, ולכן ה־forensic diff נשאר שימושי. ערכי runtime מגיעים מהגדרות WordPress ולא מקובץ committed.
