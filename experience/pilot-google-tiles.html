העיר האמיתית, ישר מהלוויין — על שדה דב

הדף הזה מזרים את מודל התלת־ממד הפוטוריאליסטי של גוגל (אותו מודל של Google Earth) וממקד אותו על רובע שדה דב. זה ניסוי צד — לבדוק איך זה מרגיש מול ההדמיה האמנותית שלנו — והוא רץ רק עם מפתח API שלך. שום מפתח לא שמור בקוד.

  1. נכנסים ל־Google Cloud Console → יוצרים פרויקט (או בוחרים קיים).
  2. ב־APIs & Services מפעילים את Map Tiles API.
  3. ב־Credentials יוצרים API Key (מומלץ להגביל אותו ל־Map Tiles API ולדומיין שלך).
  4. מדביקים את המפתח כאן למטה — או פותחים את הדף עם ?key=AIza…
💰 מודל העלות: החיוב הוא לפי "root tileset requests" — טעינת סשן נחשבת פעם אחת, והאריחים עצמם בחינם בתוך הסשן. יש מכסה חינמית חודשית נדיבה (אלפי טעינות), כך שפיילוט פנימי כמעט תמיד יישאר בחינם. לפני חיבור לאתר חי — לבדוק את התמחור העדכני בדף Map Tiles API.
המפתח נשאר אצלך: הוא עובר רק כפרמטר ב־URL של הדפדפן שלך, ישירות מול שרתי גוגל.
